# OpenNNU

**南师大开放课程资料共享计划 · 让后来的人，不必再从零开始。**

[浏览 Web 资料库](https://cobaltjiang.github.io/OpenNNU/) · [贡献资料](CONTRIBUTING.md) · [反馈与纠错](https://github.com/CobaltJiang/OpenNNU/issues/new?template=correction.yml)

OpenNNU 由学生发起，收集、整理可以公开分享的课程资料，让零散的学习积累能够被找到、被理解、被接着完善。项目非学校官方网站。

## 项目缘起

*改写自网红2分作文《止战之殇》，个人整活向。*

期末考试还有3个小时降临南师大，NNU各大媒体平台将这条消息传唤的沸沸扬扬:它的到来，是救赎还是毁灭，我无从得知，众说纷纭，我只想先下个去年的课程期末试卷。

宇宙无穷，人生微渺，我从一无所有中来，自当归于虚无。同样归于虚无的，还有期末考试之后便无处寻觅的试卷了。偶尔，只在闲鱼或小红书上学长学姐的商品页找到，零零散散，如桃花坠入深渊。

学期很长，自学不难。说到底，最终的这些学习功利上来说(显然笔者不这么认为）只是为了取得考试的分数。只要反复认真研究试卷，分析有方，理论上就能得到不错的分数。可惜，没有试卷。

关于期末考试，初听闻于暑假，我年少，它缥缈，翻翻b站大学生期末周的视频，“哇”，很好玩。可惜后来踏入NNU的大门，阶段测验也逐渐逼近；有的课听完了课也许不知所云，也许只是压根不想听，只想自己探索。或许我只是按部就班地上课写作业，也不知道自己最终面对考试又将如何下笔。总之，我得找往年的期末试卷。

信息筑起壁垒，金钱划下鸿沟。我和那些学习资料总隔着冰冷的数字，我等了一次又一次。

可惜不悔梦归处，只恨太匆匆，不知什么时候起，“真题”变成了AI乱出题，诚然多了一份人情味，少了一份预制感，但千篇一律的题和漏洞百出的答案相结合，让我失去了对其往日的热爱，或者它也不能称之为那个它了。

可宇宙苍茫，谁又能主宰学校的期末试卷呢。其实南师一切自有定数，我不信奉绩点，但我信仰世界。也许那全知全能的主会将仁爱的期末试卷撒下考场，在我活着，或在我死后。

期末考试降临了，在学正楼。没有谈判，硝烟中，炮火轰鸣中，大学生活褪去了色彩。

我到了考场，因为我必须来。作为新时代新青年，肩负历史史命与伟大复兴重担，提高GPA，舍我其谁?

可拿到试卷那一刻，我才意识到自己有多弱小，他比自由女神像还要大，尽管我没去过美国，但我刷过视频。

期末考试停下了进攻的脚步，低头看我示意我把手给他。我不敢拒绝却也止不住的颤抖。原来他是要我手中的试卷啊。看来无论何等高级的生命终无法抵御分数的诱惑。

一颗子弹贯穿我的胸膛，临死前耳畔传来的话语，在说我通敌。

哈哈哈，这就是人性吗？期末考试我开始理解你了，

不过，突然.好想做张...试卷...啊….....

## 当前进度

已导入提供的本学期开课清单：**2,011 门课程、5,065 个教学班、38 个开课单位**。按课程号合并教学班，同名但课程号不同的课程分别保留。正式收录资料为 **0 份**，与开课目录独立统计。

Web 界面支持按课程名、课程号和教师检索，按开课单位、校区和课程类型筛选，分页浏览、教学班详情、浏览器收藏及免登录文件投稿。资料经审核后收录。

## 开始贡献

在 [Web 投稿页](https://cobaltjiang.github.io/OpenNNU/#/contribute) 选择文件并填写资料信息，直接上传，不需要 GitHub 或 ChatGPT 账号，也不用填写网盘链接。文件先私下待审，审核通过后由维护者的 GitHub 账号收录。每次 1–5 个文件，单个不超过 50 MB、合计不超过 100 MB。

熟悉 Git 的同学可阅读 [贡献指南](CONTRIBUTING.md) 后提交 Pull Request。欢迎原创笔记、复习提纲、习题解析和取得分享许可的往年试卷。

## 本地运行

前端需要 Node.js 22 或更高版本，**无需安装第三方依赖**。上传后台的依赖与部署独立，见 [上传服务说明](upload-service/UPLOADS.md)。

```sh
npm run dev
# 打开 http://127.0.0.1:4173

npm run check  # 校验课程、来源字段和本地文件
npm test       # 检验检索与投稿逻辑、目录规则
npm run build # 生成 dist/，仅发布索引中列明的资料文件
npm run preview

npm run import:courses # 从 catalog/current-semester.csv 重新导入
# npm run import:courses -- "新的课程清单.csv"
```

不应直接双击 `index.html`；浏览器对本地文件的数据读取存在限制。使用上述本地服务器即可。

## 网站更新

`main` 分支的提交通过 GitHub Actions 校验、测试、构建后，部署到 GitHub Pages。Pull Request 只进行检查，不部署。已收录资料保存在可审查的 JSON 与文件目录中。独立的上传服务使用 D1 与私有 R2 暂存投稿；前端不含密钥，GitHub 凭据不离开维护者本机。维护流程见 [上传服务说明](upload-service/UPLOADS.md)。

首次部署需在仓库 `Settings → Pages → Build and deployment → Source` 选择 `GitHub Actions`。完整流程见 [.github/workflows/pages.yml](.github/workflows/pages.yml)。

## 来源与许可

代码使用 [MIT 许可证](LICENSE)。**该许可证不覆盖课程资料**：每份资料单独记录作者、来源与分享许可，原卷、回忆版、自编题及答案校对情况应如实标注。没有确认分享许可的资料不放入公开仓库，也不写入公开索引。

发现资料错误或需要更正、撤下，请通过 [反馈模板](https://github.com/CobaltJiang/OpenNNU/issues/new?template=correction.yml) 联系维护者。
